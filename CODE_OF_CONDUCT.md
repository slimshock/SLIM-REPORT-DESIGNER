# Code of Conduct

Slim Report Designer is an open-source project for the Python community. Contributors are expected to communicate respectfully and focus on technical merit.

## Expected Behavior

- Be respectful and constructive.
- Welcome differing viewpoints and experience levels.
- Give feedback that helps improve the work.
- Keep discussions focused on the project and its users.

## Unacceptable Behavior

- Harassment, threats, insults, or discriminatory language.
- Personal attacks or sustained disruption.
- Publishing private information without permission.
- Conduct that makes participation unsafe or unwelcome.

## Reporting

If you experience or observe unacceptable behavior, report it to the project maintainers. Reports will be reviewed with care and handled as confidentially as practical.

## Enforcement

Maintainers may remove comments, close issues or pull requests, or restrict participation when behavior violates this code of conduct.
