# Cloning

Domain models support explicit deep cloning.

```python
cloned_report = report.clone()
cloned_page = page.clone()
cloned_object = report_object.clone()
cloned_style = style.clone()
```

## ID Behavior

Clones receive new ids by default:

```python
cloned = report.clone()
```

This prevents accidental duplicate ids when cloning a page, object, or full report for editing.

Preserve ids only when you explicitly request it:

```python
cloned = report.clone(new_ids=False)
cloned_object = report_object.clone(new_ids=False)
cloned_page = page.clone(new_ids=False)
```

`report.copy()` is a compatibility helper that deep-copies while preserving ids.

## Report Reference Remapping

When `report.clone()` creates new ids, it also remaps known internal references:

- object `band_id`
- object `layer_id`
- object property `asset_id`
- object property `style_id`

Named style keys are treated as style ids and are regenerated by default.

## Assets

Assets are deep-cloned by default:

```python
cloned = report.clone()
```

Use shared asset references when the cloned report should point at the same asset objects:

```python
cloned = report.clone(share_assets=True)
```

When assets are shared, their ids and object references are preserved for those shared assets.
