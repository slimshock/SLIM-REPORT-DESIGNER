# Roadmap

Slim Report Designer is early alpha. The roadmap is intentionally practical and may change as the API and designer mature.

## Completed

- Python Report API
- JSON serialization
- HTML preview
- PDF export
- Flask integration
- Static designer UI
- Designer canvas
- Style inspector
- Page properties
- Image object
- Zoom/grid/snap
- Undo/redo
- Multi-select
- Align/distribute/layers
- Lock/unlock
- Bands
- Data Fields panel
- Binding picker
- Repeating Detail rows
- Basic Table Object
- Basic pagination for repeating Detail rows and Detail-band tables
- Barcode/QR objects

## Next

- Advanced table features
- Advanced pagination controls
- Group headers/footers
- Django adapter
- FastAPI adapter
- Public release packaging
